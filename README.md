# Sex-different phenotypic correlations: Due to genes or environment?

Code for analysing sex differences in phenotypic, genetic, and environmental correlations between complex traits.

This repository contains the code used in the corresponding [medRxiv preprint](https://doi.org/10.64898/2026.07.13.26357694):

> Fritz A, Darrous L, Bønnelykke K, Pedersen AG, Kutalik Z. *Sex-different phenotypic correlations: Due to genes or environment?*

**DOI:** [10.64898/2026.07.13.26357694](https://doi.org/10.64898/2026.07.13.26357694)
